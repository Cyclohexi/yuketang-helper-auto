# v2.2.1 · 课堂 AI 自动化

本次发布包含三个可独立开关的课堂 AI 功能，并于 2026-10-22 修订便携包，修复自动更新。

- **题目预分析**：加载后提前分析未发布题目并缓存答案；分析提醒展示总数、成功数与失败数，老师发布后按设置作答。
- **AI 请求失败自动重试**：临时网络错误或超时后最多额外重试两次，减少偶发请求失败；密钥或答案格式错误不反复请求。
- **截止未提交自动强制补交**：对活动课堂中已截止但未提交的题目，使用 AI 答案自动尝试一次补交；是否接受由平台决定。
- **修复自动更新**：网络波动或 HTTP/2 断流时自动重连续传，下载失败保留进度；修复点击“重启更新”后未完成升级、未自动重启的问题，安装前继续校验更新包完整性。

三个功能均可在设置中独立开启或关闭。预分析保留默认开启，重试与自动补交默认关闭；预分析需要开启 LLM 自动生成，自动补交还需开启托管提交。关闭相关开关后停止安排后续操作。

下载本页附件 **`YuketangHelper-v2.2.1-Windows-x64-Portable.zip`**，解压后运行 **`YuketangHelper.exe`**。`update-win32-x64.json` 由程序读取，无需手动下载。

**升级提示**：本次替换的是 v2.2.1 同版本便携包。已安装原 v2.2.1 的用户不会收到同版本升级提示，需手动下载替换一次；v2.2.0 用户可尝试应用内更新，若下载或重启失败，也请手动升级。替换前关闭旧程序，保留固定配置目录 `%LOCALAPPDATA%\YuketangHelper` 及程序旁原有的 `ykt-helper-data`，不要删除或用空目录覆盖。
