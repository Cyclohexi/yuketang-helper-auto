# 开发变更记录

本页记录源码及开发维护变化，不作为便携版发布说明。重要用户功能见根目录的[更新日志](../../changelog.md)；不需要为每次小修改创建记录。

## 2026-10-21

- 修复重复运行 BAT 只聚焦旧界面的问题：源码启动前正常关闭已核对身份的同配置旧窗口，防止旧源码或便携版接管启动；等待退出后启动最新构建，不强制结束进程。新增 `-DebugProfile` 隔离验证入口，保留后台隐藏启动和检查模式。
- 公开更新范围写入项目级规则：README 版本记录、根 changelog、Release 与应用更新说明只展示计划进入便携版的重要用户变化。当前待发布栏目只展示 AI 预分析及相关提醒。
- 同步检查允许源码变更同步公开更新日志或开发变更记录，避免仅维护源码时被迫增加公开条目。

## 2026-10-20 · 源码启动与本地维护

以下内容从公开未发布日志移至此处，实际实现和使用说明保持不变。

- BAT 默认后台启动，自动退出命令窗口，软件界面保持可见；失败时弹窗提示，新增 `-ShowConsole` 排查入口与独立启动日志。
- Windows 配置、登录会话及缓存统一到 `%LOCALAPPDATA%\YuketangHelper`，源码 BAT 和新构建 EXE 共用，不受程序更新目录影响。
- 首次启动复制已有配置，不覆盖固定目录、不删除旧数据；优先保留已配置 profile，调试数据独立且不导入真实凭据。
- 增加项目级 `AGENTS.md`、维护清单与 `npm run sync:check`，同步检查版本、代码和基本文档，确保新增开发文档进入 Git。
- 将用户数据和备份加入公共忽略规则；清理可再生成的打包缓存、重复 ZIP 及遗留安装工具依赖，保留正式附件与数据备份。
- 修复 Windows 一键启动脚本的编码、换行与路径处理，优先运行源码，必要时自动构建。
